# Local GraphNav Maps

This directory is for local GraphNav maps, downloaded arena maps, and backups.

Map contents are ignored by git because they can be large and may contain site-specific geometry or operational data.

Recommended local names:

- `maps/backups/`: backups of maps that were already loaded on the robot before Kinesis work.
- `maps/ad-ports-arena.walk/`: downloaded AD Ports arena map after recording.

Do not commit robot/site map data unless the project owner explicitly approves it.
